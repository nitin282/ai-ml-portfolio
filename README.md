# Nitin Chouhan — AI/ML Portfolio

A responsive React + CSS portfolio starter with a futuristic dark visual identity, animated AI hero graphic, skills, projects, and contact section.

## 1. Install Node.js
Install the current LTS version from https://nodejs.org/ if Node.js is not installed.

Check installation:
```bash
node -v
npm -v
```

## 2. Run the portfolio
Extract this ZIP, open the extracted `ai-ml-portfolio` folder in VS Code, then run in the terminal:

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## 3. Personalize before publishing
Search these files and update:
- `src/main.jsx`: intro, skills, project descriptions, GitHub/LinkedIn URLs, email address.
- Replace `your.email@example.com` with your real professional email.
- Replace generic GitHub and LinkedIn links with your profile URLs.
- Add repository links and actual screenshots to projects.
- Keep metrics (like accuracy) only if you can verify them from your own project results.

## 4. Build for production
```bash
npm run build
npm run preview
```

## Design choices
- Dark navy background with cyan/blue accents
- Responsive grid and project cards
- CSS-only orbit graphic and floating cards
- Reduced-motion accessibility support
- No stock images required: the hero graphic is made with CSS and Lucide icons
